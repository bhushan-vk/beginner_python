## Getting Started

1. Create project environment `py -3 -m venv .venv`
2. Select and Set Python Interpreter `.\.venv\Scripts\python.exe`
3. Update pip `python -m.ve pip install --upgrade pip`
4. Install packages `pip install -r requirements.txt`
5. Run Project `python manage.py runserver`

## Note

- Python 3.11
- To Activate venv `.venv\Scripts\activate` (sometime it doesn't)
- Use Command Prompt, it shows `(.venv) C\path...>` if your using venv
- To Add new app `python manage.py startapp --appname--`
- To Add or Update `requirements.txt` run `pip freeze > requirements.txt`
